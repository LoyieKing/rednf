# 数据库

- 引擎：MySQL 5.7（`docker/mysql/conf/dnf.cnf`：`sql_mode=NO_ENGINE_SUBSTITUTION`、`utf8`）。
- 初始数据：子模块 `.origin_1031/build/dnf_data/home/template/init/init_sql.tgz`（含建表与必需的种子数据，
  如 `d_taiwan.db_connect`、`taiwan_prod` 商城、频道表等），由 `docker/mysql/initdb/10-dnf-schema.sh` 导入：

| 库 | 来源文件 |
|---|---|
| `d_taiwan` `d_taiwan_secu` `d_technical_report` `tw` | 同名 |
| `d_channel_<db>` | `d_channel.sql` |
| `d_guild` | `d_guild.sql` |
| `taiwan_<db>` `_2nd` `_log` `_web` `_auction_gold` `_auction_cera` | `taiwan_cain*.sql` |
| `taiwan_login` `taiwan_prod` `taiwan_game_event` `taiwan_se_event` `taiwan_login_play` `taiwan_billing` | 同名 |

- 补充表：`docker/mysql/initdb/remake-extra.sql.in`。目前补了上游缺失的 `taiwan_<db>.cube_premium`。
  这份清单来自线上 remake 环境 `mysqldump --no-data` 与上游 `init_sql` 的差集。
- `db_connect`：`docker/runtime/db_connect.sh` 在每次启动时把各库指向容器内 `127.0.0.1:3306/3307`
  （由 socat 转发到 mysql 服务），密码字段为 `TeaEncrypt(game 密码)`。

## 服务端引用但上游与线上都没有的表

对 ORIG ELF 与 remake 源码中 SQL 字符串检索，还有一批表（多为活动 / 日志 / 统计表，如
`event_1207_attendance`、`log_randombox`、`school_member`、`user_cera_ticket` 等）在上游
`init_sql` 与线上库里都不存在。它们只在对应活动或日志路径触发，原版同样缺失；需要时按服务端日志报错补表，
补到 `remake-extra.sql.in`。
